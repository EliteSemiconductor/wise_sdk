1. Overview
    WISE SDK is a software package which supports to application development on
    ESMT ER8xxx family SoC.

2. Supported Platforms
    - ER8130A/ER8131A

3. Major Changes
    - Radio: refined software packet processing with support for a custom CRC polynomial.
4. Bug fixing:
    - Fixed XO gain-change crash by setting the DCDC EN_IPN boot default to 3.
    - Fixed WMBus gateway pre-encryption context restore and added timing control.
    - Fixed incorrect PHR configuration for fixed frame length without PHR.
