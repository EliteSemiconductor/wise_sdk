ESMT WISE SDK Release Notes

Version: 4.0008

Release Date: May 8, 2026

1. Overview
    WISE SDK is a software package which supports to application development on
    ESMT ER8xxx family SoC.

2. Supported Platforms
    - ER8130A/ER8131A

3. Major Changes
    - Added WMBUS C-mode and R-mode support in wise_radio_wmbus_api.
    - Implemented WMBUS Data Link session write support and packet filtering mechanism for meter mode.
    - Added EFUSE unique ID display in boot information and enabled EFUSE module by default.
    - Updated WMBUS RF parameters and corrected C-mode sync word implementation.
    - Updated firmware downloader: WISEDownloader_v1.0.0.exe
4. Bug fixing:
    - Fixed incorrect WMBUS C-mode sync word and removed related workaround patches.
    - Fixed incorrect platform settings causing 9006 instability and crash issues.
    - Fixed compile errors and removed redundant code in WMBUS modules.
    - Fixed RF parameter handling and internal WMBUS configuration flow.
    - Improved platform compatibility and restored stable TX/RX operation on 9006 platform.
