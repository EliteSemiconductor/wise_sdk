ESMT WISE SDK Release Notes

================================================================================
Version: 4.13.00
Git revision: 0x5b8289ed
Library: 
        libWISERadioLib_subg_soc_9006 v1.13
        libWMbusDatalink v2.00
Release Date: October 3, 2026

1. Overview
    WISE SDK is a software package which supports to application development on
    ESMT ER8xxx family SoC.

2. Supported Platforms
    - ER8130A/ER8131A

3. Major Changes
    - Updated radio library for 9006 platform to v1.13, synced with W-MBus APIs (Frame-A first-block finalization and FCB variant generation).
    - Updated WMBus Data Link library to v2.00.
    - WMBus: added DTM mechanism supporting Security Mode 0/5/7, with per-entry Security Mode configuration for gateway fixed/dynamic whitelist management.
    - WMBus: unified the gateway payload API (keeping the pre-encryption / pre-pack enqueue path) and exposed gateway admission and connection-failure callbacks.
    - WMBus: gateway added GPIO signalling for RX sync ISR / RX done ISR and TX API return.
    - WMBus demo: added "per" shell command to measure PHY packet error rate (S2/T2/C2/R2) and "demo start/stop" shell command in the WMBus PHY demo.
    - System: added Cache Control APIs for the 9006 platform (cache enabled during core init).
    - NFC: added firmware update over NFC - the ESMT NFC Tool host application (Android and PC) drives the update through the NFC control channel (demo_nfc_ctrl example).
    - NFC: added NFC control APIs (read/write data, tag configuration, interrupt callback).
    - System: added a boot fault record to report failures occurring before UART initialization.
    - Middleware: support BOD configuration via the board config file.
    - Radio: removed the fixed ANA RX gain setting during the initialization phase.
    - Docs: added WMBus datalink user and integration guides; refreshed API Doxygen comments and regenerated the WISE API HTML documentation (now including the EPD middleware).
    - Docs: added WMBus PHY Demo Guide (documents/WMBus_PHY_Demo_Guide.pdf), including the PER test frame as raw, frame-format-A and 3-of-6 encoded byte arrays.
    - Build: released Eclipse projects now include only the official ER8131P9 build configuration.
    - Build: the release package includes only the default board configuration (boards/board_default_cfg.h); configuration files for unsupported development and test-chip boards were removed.
    - Version: the SDK version is now major.minor.release (this release is 4.13.00). WISE_SDK_VERSION_T fields are now uint8_t verMajor/verMinor/verRelease/reserved (struct size unchanged); applications should print it with "%d.%02d.%02d".
    - EPD: added middleware/wise_epd for e-paper display panels (JD 122x250 BWRY and JD79651 152x296 BWR drivers); the panel is selected with EPD_PANEL in the board config file.
    - WMBus: updated RX modem parameters to tolerate +/-12% data-rate deviation for O2M and M2O frames.
    - WMBus demo: PER test now sends short frames (DLL + STL header) and reports in-order, repeated and gap counts of the access number.
    - Tools: updated WISEDownloader to v1.2.0
4. Bug fixing:
    - WMBus: fixed abnormal gateway/meter retry by finalizing the Frame-A first block with the latest FCB/FCV and CRC before RF TX.
    - WMBus: fixed meter rejecting pre-encrypted frames whose target does not match the selected connection.
    - WMBus: fixed meter receive failure caused by a timing issue.
    - NFC: fixed array-size calculation for NFC block-write data; updated NFC interrupt handling and sleep configuration.
    - Fixed compiler errors and warnings related to the new Cache Control API files.
    - Fixed Keil MDK projects failing to link because the new cache sources were missing from the project file lists.
    - WMBus demo: fixed collector ACK delay underflow that could delay the ACK response by a very long time.
    - Radio: fixed TPM calibration being skipped in WMBus mode because the WMBus TX/RX configuration was assigned after wise_radio_config().
    - Radio: TPM calibration in WMBus mode now uses the WMBus TX configuration (frequency, modulation, deviation, data rate) instead of the active channel settings, which could be the RX configuration.
    - Radio: TPM DMI sampling parameter now follows data-rate changes and is no longer altered by TPM calibration.
