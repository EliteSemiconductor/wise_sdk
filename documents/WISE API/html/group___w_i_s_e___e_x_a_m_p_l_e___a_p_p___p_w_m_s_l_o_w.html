Detailed Description

Example application: PWMSLOW continuous and one-shot output demo.

This demo uses the following Core API modules:

  • WISE Slow PWM APIs for PWMSLOW configuration/start and completion callback
  • WISE System APIs for LFOSC clock source configuration and calibration
  • WISE GPIO APIs for PWMSLOW output pin function mapping (platform dependent)

The demo supports two build modes selected by DEMO_PWMSLOW_MODE:

  • DEMO_PWMSLOW_MODE_CONTINUOUS
  • DEMO_PWMSLOW_MODE_ONESHOT

void demo_lfosc_config ( void )
static

Configure and calibrate LFOSC clock source for PWMSLOW.

PWMSLOW uses LFOSC as its clock source. This helper configures LFOSC clock source and triggers calibration before PWMSLOW is initialized.

Steps:

  1. Configure LFOSC clock source using wise_sys_lfosc_clk_src_config()
  2. Calibrate LFOSC using wise_sys_lfosc_clk_calibration()

int main ( void )

Main entry of the PWMSLOW demo application.

Common flow:

  1. Initialize demo environment
  2. Configure and calibrate LFOSC (required)
  3. Initialize PWMSLOW module
  4. Configure PWMSLOW output parameters
  5. Start PWMSLOW
  6. In one-shot mode, wait for completion callback

This demo does not return under normal operation.
