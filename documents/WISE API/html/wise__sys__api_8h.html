Detailed Description

System-level APIs for initialization, chip information, power control, DMA channel configuration, oscillator setup, and ASARADC access.

This header exposes system-wide functionality such as reset control, chip ID queries, sleep/shutdown management, DMA mapping, oscillator selection, board-level RF properties, and ASARADC sensor read operations.
