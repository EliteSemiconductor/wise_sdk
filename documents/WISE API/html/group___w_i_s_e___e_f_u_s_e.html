Read data from eFuse memory.

Reads data from the specified 4-byte aligned eFuse address.

Parameters
[in]addreFuse memory address (must be 4-byte aligned).
[out]bufPointer to destination buffer to store read data.
[in]byte_lenNumber of bytes to read (must be non-zero, 4-byte aligned, max 64 bytes).
Return values
WISE_SUCCESSData read successfully.
WISE_FAILInvalid parameters or read operation failed.
