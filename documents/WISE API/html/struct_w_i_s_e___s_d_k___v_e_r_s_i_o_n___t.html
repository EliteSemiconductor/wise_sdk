Detailed Description

SDK version information.

Contains SDK version numbers and a signature for build identification. The version is displayed as major.minor.release with minor and release zero-padded to 2 digits, e.g. 4.13.02 is major 4, minor 13, release 2: printf("WISE SDK Version d.%02d.%02d", v.verMajor, v.verMinor, v.verRelease);
