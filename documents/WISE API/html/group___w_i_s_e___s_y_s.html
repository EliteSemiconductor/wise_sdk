◆ wise_sys_cache_config()

WISE_STATUS wise_sys_cache_config ( CACHE_SIZE_CFG_T cache_size)

Configure and enable the XIP flash cache.

Selects how many ways are active (see CACHE_SIZE_CFG_T), enables the hit/miss counters, and leaves the cache enabled on success.

Note
The cache contents are invalidated as part of this call, so the first accesses afterwards run cold.
Intended for the system initialisation phase. It is called once from wise_core_init(); calling it at run time discards a warm cache.
Parameters
[in]cache_sizeCache size to apply.
Return values
WISE_SUCCESSConfiguration applied.
WISE_FAILInvalid size, or the invalidate handshake timed out. The cache is left enabled either way.
