Detailed Description

Channel-wide SPI configuration, applied once per open.

The role (master / slave) is selected by which _open function is called (wise_spi_master_open or wise_spi_slave_open), not by a field here.

Maps to:

  • Transfer Format Register (0x10) — clock_mode, bit_order, io_mode (3-wire bit), data_bit_width, data_merge.
  • SCLK divider (separate register) — clock_sel.
  • Software policy — block_mode, dma_enable.
