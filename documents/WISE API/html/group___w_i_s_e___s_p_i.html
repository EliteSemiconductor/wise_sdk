◆ WISE_SPI_CLOCK_MODE_T

enum WISE_SPI_CLOCK_MODE_T

SPI clock polarity and phase (TransFmt.CPOL bit 1, CPHA bit 0).

CPOL sets the SCLK idle level. CPHA selects the sampling edge – per datasheet: CPHA=0 samples on odd (leading) SCLK edges, CPHA=1 on even (trailing) edges. The sender shifts data out on the opposite edge so it is stable when the receiver samples.

CPOL=0 (idle LOW): CPOL=1 (idle HIGH): ┌──┐ ┌──┐ ┌──┐ ┌──┐ SCLK ───┘ └──┘ └── SCLK ──┘ └──┘ └── (drawn idle-low) ↑ ↓ -> for CPOL=1 the waveform is inverted: CPHA0 CPHA1 idle high, leading edge = falling.

With CPHA=0 the FIRST (leading) edge of each SCLK period samples; with CPHA=1 the SECOND (trailing) edge samples.

Mode CPOL CPHA SCLK idle Data sampled on

0 0 0 low 1st edge (leading, rising) 1 0 1 low 2nd edge (trailing, falling) 2 1 0 high 1st edge (leading, falling) 3 1 1 high 2nd edge (trailing, rising)

Master and slave MUST use the same mode. Mode 0 is the common default.

Enumerator
CLOCK_MODE0 

CPOL = 0, CPHA = 0. Idle low, sample on rising (1st) edge.

CLOCK_MODE1 

CPOL = 0, CPHA = 1. Idle low, sample on falling (2nd) edge.

CLOCK_MODE2 

CPOL = 1, CPHA = 0. Idle high, sample on falling (1st) edge.

CLOCK_MODE3 

CPOL = 1, CPHA = 1. Idle high, sample on rising (2nd) edge.

◆ WISE_SPI_IO_MODE_T

enum WISE_SPI_IO_MODE_T

Data wiring + lane width of the channel, set once at open.

Combines the two HW knobs that together describe the data path – 3-wire MOSI-bidirectional (TransFmt.MOSIBiDir, bit 4) and the data-lane count (TransCtrl.DualQuad, bits 23:22) – into one choice, because the only meaningful combinations are these four (3-wire is single-lane only; dual/quad are inherently bidirectional, so MOSIBiDir does not apply to them). The driver derives MOSIBiDir and DualQuad from this value.

Note
SLAVE mode supports SINGLE / 3WIRE only. DUAL and QUAD are MASTER-only: multi-lane slave RECEIVE is unreliable on this controller (premature-END / leading-byte loss – HW errata), so wise_spi_slave_open rejects DUAL/QUAD and returns WISE_FAIL.
Enumerator
WISE_SPI_IO_SINGLE 

1-bit, separate MOSI/MISO (4-wire, full duplex).

WISE_SPI_IO_3WIRE 

1-bit, MOSI bidirectional (3-wire, half duplex).

WISE_SPI_IO_DUAL 

2-bit data IO (half duplex). Master only.

WISE_SPI_IO_QUAD 

4-bit data IO (half duplex). Master only.

◆ WISE_SPI_MASTER_CLOCK_SEL_T

enum WISE_SPI_MASTER_CLOCK_SEL_T

SPI master clock selection (drives the SCLK divider).

Defines the supported set of SPI master SCLK frequencies. The HAL maps each enum value to the corresponding SCLK divider on the underlying ATCSPI200 controller.

Note
This selects the SCLK driven in MASTER mode. In SLAVE mode the master drives SCLK, so this field is ignored; the slave can only RECEIVE SCLK up to 10 MHz reliably (do not clock a slave faster than E_SPI_CLOCK_SEL_10M).

◆ wise_spi_slave_get_recv_count()

uint16_t wise_spi_slave_get_recv_count ( uint8_t spi_channel)

Get the number of bytes received by the SPI slave.

Parameters
[in]spi_channelSPI channel index.
Returns
Number of bytes received in the last transaction.
Note
The underlying hardware counter (SLVDATACNT.RCNT) is 9-bit, so a single transaction can carry at most 512 bytes and the count WRAPS to 0 at exactly 512 (values 0..511 are distinct). After a completed transfer a returned 0 therefore means 512 bytes were received. Transfers larger than 512 bytes must be split into multiple transactions.
