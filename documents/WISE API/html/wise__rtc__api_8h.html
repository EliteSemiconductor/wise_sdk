RTC counter field ranges

Valid ranges for WISE_RTC_CNT_T / WISE_RTC_ALM_CFG_T fields.

Out-of-range values are rejected with WISE_FAIL. The day counter counts days since the RTC was enabled (not a calendar date) and wraps every 32 days.

Detailed Description

RTC (Real-Time Clock) driver APIs.

This header provides the interface for configuring and using the on-chip Real-Time Clock, including current time read/write, alarm configuration, start/stop control, and event callback registration.
